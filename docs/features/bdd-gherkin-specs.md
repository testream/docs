# BDD Gherkin Specs

:::info Coming Soon
With Testream's BDD Gherkin Specs feature, you can write your acceptance criteria in plain language using Gherkin syntax and **Atlassian Rovo AI** in your Jira issues and asses them against the test results and context automatically captured by Testream. This allows you to ensure that your tests are aligned with your requirements and easily identify any gaps in test coverage.
:::
